# Java fixture: `shop`

Written from scratch for repo-compass tests. It compiles in spirit but is not
built; it exists to exercise the indexer: overloaded constructors and methods,
varargs, nested/inner classes, enums with constant bodies, records, annotation
types, explicit/wildcard/static imports, method references, lambdas, anonymous
classes, and a distractor class whose method names collide with the real ones.
`broken/Broken.java` contains a deliberate syntax error.
